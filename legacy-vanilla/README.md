# Tech Manager website UI

A responsive, single-page agency/product website concept for Tech Manager.

## Preview locally

Open `index.html` in a browser, or run a local server from this directory:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Included sections

- Sticky navigation with mobile menu
- Hero section with animated connected-systems illustration
- Five service cards: Optical, Broadcast, Web, Surveillance and Custom Software Manager
- Selected work / portfolio showcase
- Project approach, about section, enquiry form and footer
- Responsive layouts, scroll reveals, spotlight hover, subtle 3D tilt and magnetic-feel CTAs

## Before publishing

1. Replace the sample project visuals and wording with approved screenshots, client names and real case-study details.
2. Add your official contact email, phone / WhatsApp, social links and company details.
3. Connect the enquiry form to your email service or backend. The current form is a front-end demo and copies the enquiry details to the clipboard after validation.
4. Confirm the brand colours and final logo. The current mark and visual system are design placeholders.

## Design direction

Dark editorial technology aesthetic with lavender / lilac gradients, cyan accents, soft grid lighting and glass-like panels. Motion and interaction patterns are inspired by the playful, interactive style of Kokonut UI; no Kokonut UI component source is bundled here.
